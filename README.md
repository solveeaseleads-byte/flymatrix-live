# FlyMatrix v3

**Search smarter. Travel prepared.**

FlyMatrix is a global flight search and travel-intelligence platform built around flight discovery, travel planning, tourism intelligence, affiliate services, alerts, and travel preparation.

## Technology

FlyMatrix uses:

- React
- Vite
- Express
- Supabase
- Duffel
- Travelpayouts
- Paystack
- Resend
- Telegram

## Requirements

- Node.js 20+
- npm
- Supabase project
- Provider credentials for the services you enable
